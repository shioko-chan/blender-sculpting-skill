# Sources and rights review (2026-10-15)

This skill's instructions and helper script were written independently. No upstream text or code was copied into this package. Links below are study references and provenance for the broad workflows.

- [edemaistre/blender-expert-skills](https://github.com/edemaistre/blender-expert-skills), especially [blender-sculpting](https://github.com/edemaistre/blender-expert-skills/blob/main/blender-sculpting/SKILL.md) and [blender-expert](https://github.com/edemaistre/blender-expert-skills/blob/main/blender-expert/SKILL.md): original 13-skill Blender family. Its README describes Blender 5.2.1 testing and scripts shared between siblings. At review time, its root file listing showed no `LICENSE`, and the attempted `/blob/main/LICENSE` did not resolve. Treat its materials as reference only unless the owner clarifies reuse rights.
- [Scenario Blender family README](https://github.com/scenario-labs/skills/blob/main/skills/dcc/blender/README.md): identifies its Blender family as ported from the edemaistre repository, with `scenario-` naming and packaging changes. Its [sculpting](https://github.com/scenario-labs/skills/blob/main/skills/dcc/blender/scenario-blender-sculpting/SKILL.md) and [expert](https://github.com/scenario-labs/skills/blob/main/skills/dcc/blender/scenario-blender-expert/SKILL.md) skills influenced the emphasis on staged review, coarse-to-fine forms, and different headless versus live capabilities. Scenario marks the repository [MIT](https://github.com/scenario-labs/skills/blob/main/LICENSE), copyright 2026 Scenario. Because this package contains no copied Scenario code or substantial text, it does not relicense or bundle that project.
- [Scenario ZBrush character/creature](https://github.com/scenario-labs/skills/blob/main/skills/dcc/zbrush/scenario-zbrush-character-creature/SKILL.md) and [stylized](https://github.com/scenario-labs/skills/blob/main/skills/dcc/zbrush/scenario-zbrush-stylized/SKILL.md): conceptual prompts for anatomy, structural causes of detail, deliberate exaggeration, and silhouette checks. ZBrush-specific operations were translated into Blender choices in `blender-method-map.md`; none of their ZBrush scripts are included.
- Blender's own [Multiresolution documentation](https://docs.blender.org/manual/en/latest/modeling/modifiers/generate/multiresolution.html) and [render API](https://docs.blender.org/api/current/bpy.ops.render.html) are the authority for those Blender features. Check the installed version before running version-sensitive `bpy` code.

For any later incorporation of upstream files, inspect the license of the exact source and preserve its notice as required. This package has no declared outbound license; choose one with the owner before publishing if redistribution terms are desired.
